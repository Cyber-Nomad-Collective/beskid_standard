LambdaCall	Lambdas and function-typed parameters lower.
ContractDispatch	Contract methods can be called on a `where T: Contract` generic.
GenericLocal	Locals whose type is a type parameter lower.
ThisMethodCall	A method can call another method on `this`.
MatchSelf	A `match` arm can yield `self` inside a method.
NestedField	Nested field access lowers through a generic struct field and cross-module struct types.
FieldOnCall	Field access directly on a call result lowers.
CallInArrayLiteral	Array literals may contain concatenations of call results.
EnumArrayLiteral	Array literals of enum values lower.
BulkArgs	`bulk` parameters accept several call arguments (`List.Of<i64>(1, 2, 3)`).
FloatToIntCast	`i64(x)` on an `f64` lowers.
FloatInterpolation	Interpolating an `f64` lowers and prints its value.
BoolInterpolation	Interpolating a `bool` prints `true`/`false`.
EmptyConcat	Concatenating two empty strings yields a valid empty string.
MinI64Interpolation	Interpolating the minimum `i64` prints all its digits.
TimeToUtc	`Core.Time.ToUtcDateTime` passes analysis (corelib fix: declare `nanos`, `seconds`, `days`, `daySeconds`, `remaining`, `year`, `month` as `mut` in `Time.bd`).
StringOrdering	Strings support `<` (feature request; `String.Less` is the workaround).
ParameterShadowsField	A method parameter named like a field of `this` refers to the parameter (0.5.2 silently reads the field).
QualifiedGenericCall	A fully qualified generic call (`Core.Collections.Queue.New<i64>()`) lowers.
